Frequently Asked Questions (FAQ)

Welcome to Perchance.org's Clean Text to Text (T2T) AI generator. This is a simple large language model using Perchance's backend AI T2T system.

To Start

To use this generator, simply:

  1. Switch to the Prompt tab.

  2. At the message box below, type in your query.

  3. Hit the send button next to the message box.

  4. Wait for response and continue your conversation. It can take minutes depending on server loads.

Context Aware

This application is made with context-aware facility by default. It also means the previous messages are fed together with your new query. Therefore, the longer the conversation, the heavier the used token counts.

For effective use, try keeping the conversation as simple, single topic, and concise as possible. 1 Token is roughly about 3/4 of an English word. You can budget accordingly.

Clean Design

Apart from context-aware feature, this generator doesn't introduce anything else. Hence, it is a great tool to debug and analyze the current backend AI states and develop your prompt.

Saving Session

By default, the session is not saved in both backend server and in your browser.
To save, select the DOWNLOAD button when the prompt is free to download the session entire transcript as .txt file.
To upload, select the UPLOAD button when the prompt is free from running. If the transcript has an empty AI response, the generator will automatically perform the request with the backend server.

Restart Session

Select the CLEAR button when the prompt is free. This will reset a whole new session.

Guard Rails

For front-end (as in web interfaces), the maintainer(s) does not introduce any additional guard rails (default sentences prefix/append to your prompt. Any guard rails can be jail-broken easily by anyone on client-side so it is a waste of efforts without outcome guarentees.


However, depending on backend AI model, some LLM (notably DeepSeek) comes with default guard rails within them. Hence, we can safely state the AI is somewhat guarded. You can query the AI model to learn more about its capability.
